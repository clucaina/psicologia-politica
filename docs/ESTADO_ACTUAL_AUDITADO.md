# Estado actual auditado (octubre 2026)

## Conflictómetro
La UI reacciona, pero varias interacciones no producen suficiente valor analítico:
- categorías Vivienda/Empleo/Migración/Salud/Seguridad no desembocan claramente en datos/gráficos;
- faltan leyendas cuantitativas y diferenciación 0/sin dato;
- comparación territorial insuficiente;
- no hay correlaciones estadísticas reales;
- timeline necesita afectar datos/series, no solo hitos;
- Pregunta a España debe ser visible, fiable y basada en datos;
- Madrid debe usar geo ES30, no cifras nacionales reutilizadas.

## Datos de España
- archivo: 50.031 observaciones, 318 indicadores, 41 fuentes;
- interfaz pública expone muy poco del archivo;
- filtros Territorio y Población/subgrupo necesitan poblarse desde DB;
- faltan visualizaciones y páginas analíticas completas por indicador.

## Analizador
- detector local todavía demasiado superficial;
- falsos positivos posibles;
- guardar análisis carece de feedback claro;
- falta metodología, export/historial y disección factual/argumental profunda.

## Integración
Hoy las herramientas se enlazan, pero no comparten un flujo analítico.
Objetivo: afirmación -> datos -> mapa -> comparación/correlación -> fuente.
