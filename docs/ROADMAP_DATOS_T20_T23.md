# Roadmap de datos T20–T23 (preparar fuera de Work)

## T20 — Seguridad / justicia
Prioridad:
- criminalidad registrada por CCAA/provincia;
- tasas por 100.000;
- delitos violentos;
- libertad sexual;
- ciberdelincuencia;
- delitos de odio;
- evolución temporal;
- fuentes Interior/CGPJ/INE cuando corresponda.

## T21 — Vivienda / economía territorial
- precio venta/alquiler;
- esfuerzo de vivienda;
- compraventas;
- lanzamientos/desahucios;
- renta;
- salarios/empleo;
- oferta, construcción y hogares;
- CCAA/provincia/municipio cuando exista.

## T22 — Salud / vulnerabilidad
- suicidio por sexo/edad/territorio;
- salud mental;
- mortalidad;
- dependencia/discapacidad;
- pobreza infantil;
- listas/recursos sanitarios cuando la fuente permita comparabilidad.

## T23 — Ciudadanía / política / psicología social
- participación/abstención;
- resultados y cambios electorales como variables descriptivas;
- confianza institucional;
- percepción de problemas;
- polarización/actitudes donde existan series válidas.

Todas las tandas se entregarán como JSON conforme a DATA_BATCH_SCHEMA,
con URL, fecha, unidad, geografía y flags metodológicos; Work no debe recopilar estos datos.
