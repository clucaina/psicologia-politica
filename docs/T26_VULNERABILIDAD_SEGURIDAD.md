# T26 — Vulnerabilidad y seguridad (2025)

Lote nuevo para NPL/Conflictómetro. Añade 85 observaciones verificadas: 80 de ECV 2025 (AROPE, riesgo de pobreza, carencia material/social severa y baja intensidad de empleo para España + CCAA + Ceuta/Melilla) y 5 observaciones nacionales de cibercriminalidad, odio y trata/explotación.

## Reglas de visualización
- ECV: mostrar como encuesta/estadística oficial, no como diagnóstico individual.
- Cibercriminalidad/odio: rotular siempre “hechos registrados/conocidos”; nunca “delitos reales” o prevalencia.
- Trata: “víctimas liberadas” es output operativo policial, no prevalencia poblacional.
- 0 es un valor válido; null significa ausencia.
- No correlacionar automáticamente vulnerabilidad con criminalidad. Cualquier correlación debe indicar N, periodo, nivel territorial, método, r/ρ y advertencia explícita de no causalidad.

## Integración Conflictómetro
Permite nuevas capas CCAA: AROPE, pobreza, privación severa y baja intensidad de empleo. Para seguridad, usar series nacionales hasta disponer de desglose territorial homogéneo y comparable. No colorear CCAA con un valor nacional.
