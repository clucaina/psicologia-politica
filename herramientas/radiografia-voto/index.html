Antes de interpretar un voto

Una abstención no es un «no» encubierto, una iniciativa rechazada no significa que todas sus medidas se debatieran por separado y tomar en consideración no equivale a aprobar una ley.

Método verificable y límites

Un resultado que explica sus límites

Solo se comparan respuestas afirmativas o negativas contra el sentido mayoritario registrado para el grupo parlamentario en el acto concreto. La abstención, la ausencia y el empate no se imputan como apoyo ni rechazo.

Dentro de cada temática calculamos la proporción ponderada de coincidencias. Después promediamos las temáticas que tengan datos comparables, concediendo igual peso a cada temática para no sobrerrepresentar vivienda. La puntuación no es una probabilidad de votar a ese grupo.

Una muestra con menos de dos temáticas comparables por grupo se muestra como insuficiente para un resumen transversal. Los resultados se acompañan de cobertura, las respuestas omitidas y el sentido de cada voto, evitando que un 100 % basado en un único caso parezca concluyente.

Estas ocho votaciones son una primera muestra editorial. No constituyen un censo de toda la legislatura. La selección no es estadísticamente representativa y puede producir coincidencias inestables. Para una comparación de programas se requiere una matriz documental distinta, con versiones fechadas y fuentes explícitas. Nunca se infiere el programa a partir de un voto.
